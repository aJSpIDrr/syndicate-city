# Syndicate City — Art Still Needed

Done so far: rank portraits and signature weapon tiers for **The Syndicate** and **The Firm**, rank portraits for **The Triad**.

## Delivery tips
- Grids (atlases) like your current ones are perfect: uniform cells, dark gutters between them, one row per set of 5.
- Keep each file **under 10MB** (JPG at ~85% quality is ideal) so it can be pulled from Drive.
- Sizes below are the minimum for sharp display on phones and retina screens. Bigger is fine, same shape.
- Style that reads best at small sizes: bold comic-noir, strong outlines, saturated colour, subject centred, simple dark background.
